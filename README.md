# Data Science Portfolio

A collection of applied data science projects covering the full lifecycle: database design, programming, statistics, machine learning, deep learning, optimization, and MLOps deployment.

## Skills

- Languages & Libraries: Python (pandas, NumPy, scikit-learn, statsmodels, TensorFlow/Keras, Matplotlib/Seaborn, mlxtend), SQL, PuLP
- Databases: Relational design & normalization (MySQL), NoSQL/document design (MongoDB)
- Machine Learning: Linear & logistic regression, gradient boosting, k-means clustering, PCA, ARIMA forecasting, CNNs, embedding-based neural networks
- MLOps / Deployment: Versioned data pipelines (DVC), experiment tracking (MLflow), REST API model serving (FastAPI), containerization (Docker), unit testing
- Visualization & Storytelling: Executive dashboards, matplotlib/seaborn
- Optimization: Linear / mixed-integer programming (PuLP)
