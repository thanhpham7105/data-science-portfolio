# Business Analytics Automation

## Overview
Designed and implemented a Python program that automates financial-health analysis of a business dataset -- planning the logic with a flowchart and pseudocode before writing the code, then building out the visualizations to communicate the results.

## What's here
- `financial_health_analysis.py` -- loads a business dataset with pandas, checks for and logs duplicate records, computes grouped descriptive statistics (mean/median/min/max) by state, flags businesses with a negative debt-to-equity ratio, and computes a debt-to-income ratio with explicit divide-by-zero handling.

## Approach
1. Plan the program logic with a flowchart and pseudocode before writing any code.
2. Implement with pandas: import, validate (duplicate check), transform (grouped stats, derived ratios), and export.
3. Visualize the results (debt-to-income distribution, average profit margin by state, debt vs. revenue) to support a non-technical audience.

## Skills demonstrated
Program design (planning before implementation), pandas data wrangling, defensive coding, descriptive statistics, chart-based communication of results.
